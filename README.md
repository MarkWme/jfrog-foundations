# 🐸 JFrog Foundations

## Introduction

Welcome to the JFrog Foundations Workshop! This workshop is designed to provide you with a comprehensive understanding of JFrog's suite of products and how they can be integrated into your software development lifecycle. 

You can work through this content on your own, or you may be doing this as part of a workshop with a JFrog expert.

## Prerequisites

A personal GitHub account is required to complete the workshop exercises. If you don't have one, you can create a free account at [GitHub](https://github.com/join).

> **NOTE:** If you have an enterprise GitHub account, it may have restrictions that prevent you from completing some of the exercises. It is recommended to use a personal GitHub account for this workshop to ensure you have the necessary permissions to complete all exercises.
